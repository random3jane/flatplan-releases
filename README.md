# Flatplan desktop releases

Installers and release notes for Flatplan on Apple silicon Macs.

[Download the latest test release](https://github.com/random3jane/flatplan-releases/releases)

The current diagnostic channel is unsigned and requires manual installation. Quit Flatplan before replacing the app. Projects, documents and settings remain in `~/Library/Application Support/Flatplan Single Alpha/`. Do not delete that folder when updating.

No GitHub account or token is required to download these assets. Source code and diagnostic reports are private and are not published here. Please share diagnostic exports privately with the developer, not in public issues.

Signed automatic updates will be offered after Developer ID signing, notarisation and the end-to-end update gate have been verified.
